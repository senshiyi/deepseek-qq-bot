# 跨会话角色、记忆与批量表情增量（2026-10-23）

## 已确认范围

- 同一 QQ 联系人在授权群中可自动使用其长期笔记；私聊原文仍只供该联系人的私聊及面板主动发起的人格草稿学习。群回复不查询其他成员的私密笔记。
- 群聊可应用现有全局角色和与当前联系人的相处设定。旧文件新增开关默认关闭；本项目按本次授权开启。模型收到笔记后无法硬保证零泄漏，提示只作背景、不复述或说明笔记出处。
- 从选定联系人的近七天历史提取机器人的角色和相处方式，生成可编辑草稿。主动生成会沿用当前文字模型、密钥和账本；确认后才保存，生成失败不改角色。保留人工编辑优先及过期/并发修改保护。
- 批量导入每批最多20张、单图最多5MiB、整批原图最多20MiB。逐项展示结果，不覆盖已有素材；ID和标签可手改。自动看图打标签等待用户后续视觉 API，本轮不调用视觉、不编造标签。

## 实施分工与接点

1. `BotProfileStore.cs` / `GroupChatRuntime.cs` / `GroupChatBrain.cs`：兼容双开关、按明确触发成员绑定笔记、群角色提示与隐私限制；扩展原有合成检查。
2. `PersonaLearning.cs`：有界历史输入、严格结构输出、人格草稿；`LocalAdminServer.cs`：鉴权生成/确认接口、草稿有效期和当前角色冲突检查。`ChatApplicationHost.cs`：提供当前引擎模型工厂，沿用真实调用账本。
3. `MemeBatchImporter.cs` / `MemeLibraryChecks.cs`：预检批量额度，逐项导入与结果；`LocalAdminServer.cs`：仅批量路由放宽请求上限。`AdminWeb/`：多选、逐项预览和编辑、结果及重试；保持原单张/收到图/删除入口。
4. 管理面板补齐角色群聊开关、共享笔记说明、人格学习的选择来源/草稿预览/明确确认；补 API 与真实浏览器合成检查。

## 验证与发布

- 隔离构建，不覆盖正在运行文件；消息/管理套件重点验证QQ身份隔离、群不读私聊原文、草稿不自动保存/取消/冲突、批量部分失败和原图保护。
- 真实浏览器使用合成历史与图片，不下载用户图片，不向QQ发测试消息，不为验证重跑旧的定时测试。

- 已实现、自动检查和真实QQ验证分别记录。本轮不恢复语音，不部署视觉模型，不操作安卓虚拟手机。
