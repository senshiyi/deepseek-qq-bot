# 本地网页管理面板实施计划

日期：2026-10-21。用户已明确要求在现有项目增加角色、联系人长期记忆、表情包和运行设置四组管理功能，保留已验证的群聊、私聊与连续消息逻辑。

## 约束与实现

- 沿用 Windows / .NET 10 与普通账号 NapCat；不恢复语音，不更改 QQ、系统音频、默认设备、自启或付费服务。
- 面板由消息宿主提供 `http://127.0.0.1:17802/`，静态资源嵌入产品，不依赖 CDN、Node 或额外数据库。API 使用独立本地随机口令和同源校验，口令不打印到普通日志，不返回模型密钥。
- `BotProfileStore` 原子保存角色和手动长期记忆到忽略的 `bot-profile.local.json`。按联系人分开，只在对应私聊注入，不自动归档全部聊天。
- `MemeLibrary` 增加字节导入与标签更新，保留格式验证、库路径约束、并发锁及原素材不覆盖。
- 面板保存配置后显式“应用设置”，先取消旧会话并释放事件端口，再加载保存的白名单、频率、角色与表情标签；NapCat保持在线。状态清楚区分当前会话与保存值。
- 角色回复长度限40～3000字符（用户追加要求），表情允许比例0～100%；模型输出Token与保守费用预留一并按实际请求上限匹配。
- 现有 `GroupChatRuntime.RunAsync` 无面板测试入口保留；正式chat命令由宿主托管面板和消息会话，P/X/S/Q保持。
